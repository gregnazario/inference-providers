# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately via **GitHub Security
Advisories**: open the repo's **Security** tab → *Report a vulnerability*.
Do not open a public issue for security reports. You should get a response
within a few days.

## Scope

This repository is a public registry: the provider data under `data/` is
collected from public provider documentation and public API listings — it is
not sensitive and contains no secrets or credentials. Reports about incorrect
public data (pricing, model ids, endpoints) are ordinary data-correction
issues, not security reports — see the *Data correction* issue template.

## Supported versions

Only the latest `main` branch is supported.
